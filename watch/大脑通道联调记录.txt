  四、怎么自己复现
════════════════════════════════════════════════════════════════════════════

  准备：
    1. 手表烧好带 ble_ai 的固件（main.bin 2,574,716 字节那版）
    2. 打开 ai_brain_config.json —— provider 保持 "offline" 就能先跑，
       要接真模型就改成 deepseek / qwen / zhipu / moonshot / hunyuan / openai
       并填上 api_key

  两条命令：
    窗口 1（电脑当大脑）：
        python ble_ai_pc.py serve

    窗口 2（以手表身份提问，等手表上有了问答页就不需要它）：
        python _ser_ask2.py "你好，你是谁"

  ⚠ 手表广播只开 5 分钟。脚本开头的 RTS 脉冲复位就是把板子叫醒 + 重开广播，
    所以直接跑就行，不用管它睡没睡。

  五、现在的边界（说清楚，免得高估）
════════════════════════════════════════════════════════════════════════════

  ✅ 已经能用的
     · 手表 ↔ 电脑 双向文字通道（4/4 用例通过，含 603 字节强制分包）
     · 电脑端「大脑」自动回答，答案能完整回到手表
     · 大脑可换：本地假大脑 / 任何 OpenAI 兼容的真模型（改两行配置）

  ⚠ 还不能算「AI 助手 app」的地方
     · **手表上没有任何问答界面**：提问只能从串口 ai_send 发，
       答案回到手表后也只落在串口日志里 —— 屏幕上看不到
       （这是下一步要做的事：快捷问题按钮 + 答案显示区）
     · **还没接真模型**：需要你先申请一个 API key 填进配置文件
     · 输入只有"预设问题"或键盘型输入两种走法，语音输入（麦克风）
       是更远的一步 —— 那才是真正吃满这块板硬件的形态
