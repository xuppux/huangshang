手表上要先做什么？
  1. 没校过时的话，什么都不用做。手表开机发现时间是假的（2024-01-01）， 会自己开始广播。
  2. 等大约 15 秒。开机后蓝牙协议栈在后台起来，表盘会先亮。 上划窗口那行状态字显示「蓝牙：广播中 · 用手机对时」才是可以连了； 这之前点「连接手表」会列出空列表。
  3. 如果手表时间是对的（或者自动广播已经超时），从屏幕顶部往下划叫出上划窗口， 点一下里面的 BT 按钮。
  4. 广播开 5 分钟会自动关，超时再点一次 BT 就行。广播期间手表不会息屏， 所以不用担心连到一半断开。

连不上 / 找不到手表怎么办？
  1. 先看手表上的状态字（上划窗口里 BT 按钮下面那行）。必须写「广播中」 才是可以连的；写「启动中」就再等十几秒，写「就绪」说明广播没开，点一下 BT。
  2. 用 Chrome 或 Edge 打开这个页面。Safari 和 iOS 上的任何浏览器都不支持 网页蓝牙，手机端只有安卓的 Chrome 可以。
  3. 页面左下角显示 file:// 时，浏览器可能不允许用蓝牙。 改用同目录的 start_server.ps1 起个本地服务再打开（会给出 localhost 地址）。
  4. 列表里找不到设备：先点「搜全部设备」。 那里能看到 HS-Watch = 手表在广播，是"按服务筛选"没匹配上； 那里也看不到 = 手表根本没在广播（回第 1 条）。
  5. 连上又马上断开：广播中 / 已连接期间手表屏幕是保持常亮的，正常不会掉线。 把手表靠近电脑再试一次。
  6. Windows 上反复失败：设置 → 蓝牙和其他设备 里如果有旧的 HS-Watch 记录， 先「删除设备」，然后关掉再打开蓝牙适配器，重新点「连接手表」。
