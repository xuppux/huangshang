## ⑤ 真校一次时（推荐做，最有价值）

按这个顺序点，**每步都能当场看到数字变化**：

1. 点 **`2024 年`** → 按 **`+`** 两次 → 应变成 **`2026 年`**
2. 点 **`01 月`** → 按 **`+`** 到 **`09 月`**
3. 点 **`01 日`** → 按 **`+`** 到 **`20 日`**
4. 点 **`时`** / **`分`** → 调成**手机上的当前时间**（秒随便）
5. **顺手测一下连加**：按住 **`+`** 不放 1 秒以上，数字应该**连续往上涨**，
   而不是只 +1（不然把「日」从 1 调到 20 要点 19 下）
6. 按 **【确定】** → 卡片关闭，表盘时间应该在 **1 秒内**变成你刚设的值
7. **再验一次"写进去了"**：按 KEY1 息屏 → 再按 KEY1 唤醒 → 时间应该还在

| 现象 | 含义 |
|---|---|
| 数字能变、但按【确定】后表盘没变 | 面板和 RTC 之间断了（告诉我） |
| 按【确定】后表盘变了，但唤醒后回到 12:00 | RTC 没写进去（告诉我） |
| 全程数字都不动 | 回到 ② 的触摸问题 |

> **提示**：校时面板里的 **【确定】是安全的**，只会把时间写进 RTC，不会关机。
> 真正要小心的是第 ⑥ 条的**长按 KEY1**（那才是关机流程）。

## 如果触摸整体不通（② 是"点什么都没反应"）

不用拆机，有两条退路，你说一声我就做：

1. **串口命令**：`calib open` 开面板、`calib sel 1` / `calib inc` / `calib dec` 调、
   `calib ok` 写 RTC、`calib check` 看当前值。只是得插着电脑。
2. **查触摸驱动**：`rtconfig.h` 里 `BSP_USING_TOUCHD=1` / `TOUCH_DEVICE_NAME "i2c1"` /
   `TOUCH_IRQ_PIN 41`，开机日志有
   `I/TOUCH tp_init: touch screen found driver ... ft6146` —— 说明驱动挂上了。
   真不通就要看 I2C1 的实际波形和 FT6146 的复位脚了，那是硬件排查，另开一摊。
