# 编译 & 烧录（黄山派 × 手环表盘）

## 最短路径：一条命令

打开 PowerShell，进到 `watch` 目录：

```powershell
cd C:\Users\18058\Desktop\huangshanpai\watch
.\build-and-flash.ps1
```

它按顺序做三件事，任一步失败就停下并告诉你卡在哪：

1. **编译** —— 增量编译，改了几个文件就编几个
2. **烧录** —— 自动找串口，用 sftool 写 `bootloader` + `main` + `ftab`
3. **校时** —— 用**你电脑的当前时间**给板子的 RTC 对时

只想单独干某一步：

```powershell
.\build.ps1              # 只编译
.\flash.ps1              # 只烧录（会自动挑串口）
.\serial.ps1             # 只看串口输出（开机日志）
.\serial.ps1 -SetTime    # 单独校时
```

常用参数：

| 命令 | 作用 |
|---|---|
| `.\build-and-flash.ps1 -Clean` | 先全量重编（约 23 分钟）再烧 |
| `.\flash.ps1 -List` | 只列出串口，不烧 |
| `.\flash.ps1 -Port COM5` | 手动指定串口 |
| `.\flash.ps1 -Erase` | 整片擦除后再写（改过分区表才需要） |
| `.\flash.ps1 -Baud 921600` | 1M 不稳时降速 |
| `.\build-and-flash.ps1 -NoTime` | 不动 RTC |
| `.\build-and-flash.ps1 -SkipBuild` | 跳过编译，直接烧现有固件 |

## 关于「时间是真的吗」

表盘的时间来自 RTC，RTC 用的是 **LXT 32.768kHz 独立晶振**（开机日志里有一行
`I/drv.rtc main: RTC use LXT`），不是内部 RC 振荡器，所以走时精度是够的。

但有一条硬件限制必须说清楚：

> **这块板子的 RTC 域没有备份电池。**

所以：

| 情况 | 时间还在吗 | 依据 |
|---|---|---|
| 按复位键 / 重新烧录固件 | ✅ 在 | **已实测**：烧完再开串口读，`show_date` 仍是写入的真实时间 |
| 开关串口（CH340 会带一下复位） | ✅ 在 | **已实测** |
| 单片机进睡眠 | ✅ 在 | RTC 本来就是给这个用的 |
| 拔掉 USB（完全断电） | ❓ 大概率丢 | RTC 域要供电才走；板子上没有纽扣电池 |

**拔电这条，一分钟就能自己验证**：拔掉 USB → 等 30 秒 → 插回去 → 看表盘时间。
如果时间还在，说明 RTC 域有独立供电，那就一次都不用管了；如果变成了 2024-01-01 12:00，
就是掉了，插着电用或者每次上电对一次时。

对时不需要拆机、不需要改代码，插着 USB 跑一次就行：

```powershell
.\serial.ps1 -SetTime
```

它会发出 `show_date 2026 9 20 17 30 0`，然后紧接着发一条 `show_date` 把芯片的回答读回来
打给你看 —— 你能直接确认到底写进去没有，不用猜。

想手动敲也行，串口 **115200 是错的，这里是 1000000 波特率**：

```
show_date                      # 查看
show_date 2026 9 20 17 30 0    # 年 月 日 时 分 秒
```

> 如果希望拔电后时间还在，只有两条路：给 RTC 域加一颗纽扣电池/超级电容（硬件改动），
> 或者开机后从外部拿时间（板子有蓝牙，但要配一个手机端）。都不在现在的范围里。

## 烧录时不要做的事

- ❌ **别用另一块 USB 转串口模块给板子供电**。烧录时靠板子自己的 USB 口供电就行，
  两个电源顶在一起会出问题。
- ❌ 别在烧录过程中拔线。中途断了不会烧坏，但固件是残的，重新烧一次即可恢复
  （sftool 能自己把芯片带进下载模式，不需要手动短路）。
- ❌ 烧之前先关掉任何串口助手 / PuTTY / IDE 的串口监视窗口，串口是独占的。

## 烧不进去怎么查

| 现象 | 原因 | 办法 |
|---|---|---|
| 提示找不到串口 | 板子没插 / 驱动没装 | `.\flash.ps1 -List` 看有没有；CH340 装 CH341SER 驱动 |
| 串口被占用 | 有别的程序开着串口 | 关掉串口助手、PuTTY、IDE 的监视窗口 |
| 连不上芯片 | 没进下载模式 | 按住 BOOT → 点一下 RESET → 松开 BOOT，再烧 |
| 连上了但传输报错 | 1M 波特率不稳 | `.\flash.ps1 -Baud 921600` |
| 编译报错 | —— | 看 `build_py.log`，或者把报错发我 |

## 技术细节（不关心可以跳过）

- 烧录工具：`C:\Users\18058\.sifli\tools\sftool\0.1.16\sftool.exe`，不在 PATH 上，脚本里写死了绝对路径
- 实际执行的命令（等价于 SDK 自带的 `uart_download.bat`）：

  ```
  sftool -p COM3 -c SF32LB52 -m nor write_flash ^
      "bootloader\bootloader.bin@0x12010000" ^
      "main.bin@0x12020000" ^
      "ftab\ftab.bin@0x12000000"
  ```

- **J-Link 没装**，所以走不了 SWD，只能 UART
- 控制台是 `uart1`，波特率 `1000000`（见 `rtconfig.h` 的 `RT_SERIAL_DEFAULT_BAUDRATE`）
- 脚本会自动检查「源码比固件新」，如果编完没烧就会拦你一下，避免烧了个旧固件还纳闷为什么改动没生效
